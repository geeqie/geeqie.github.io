Behavior Options

This section describes the options presented under the Behavior Tab of the preferences dialog.

  • Delete
  • Behavior
  • Navigation
  • Debugging

Delete

Confirm permanent file delete

Prompts for confirmation before deleting files.

Confirm move file to Trash

Prompts for confirmation before moving files to the trash bin.

Confirm permanent folder delete

Enabled by default. Prompts before permanently deleting a folder and all its contents, including subfolders. The folder context menu offers both Move to Trash and Permanently Delete, each using its own confirmation setting. Disabling this option starts permanent deletion without confirmation; errors are still reported.

Confirm move folder to Trash

Enabled by default. Prompts before moving a complete folder tree to Trash as one item. The confirmation shows the number of descendant folders and all files, including hidden files, sidecars, symbolic links, and files excluded by display filters. Symbolic link targets are never traversed. If contents cannot be counted reliably, an error is shown and deletion stops.

Built-in counting and recursive operations run in the background with a progress dialog and a Cancel button. Cancellation stops further work; files already removed are not restored. Failure messages distinguish incomplete copying from a completed copy followed by failed source removal. They identify the source and destination paths, say whether an incomplete copy was removed or remains, and report how many source entries were removed. A completed copy is retained when source removal fails. Built-in deletion refuses folder trees containing mount points, including bind mounts, before deleting any contents; symbolic links are not followed. Sources that change while being copied are checked before removal and the operation stops if a change is detected. Disabling this option starts trashing without confirmation. Failed trashing never falls back to permanent deletion.

Enable Delete key

Disable this to disassociate the delete file function from the Delete key.

If Confirm file delete , above, is disabled, accidentally hitting the Delete can result in files being erroneously deleted without warning. Disabling the Delete key will prevent this. The Ctrl + D key sequence is not affected.

Use Geeqie trash location

Moves deleted files to a temporary folder, for easy retrieval of deleted files. Items in the temporary folder are retained until the maximum size is reached, at which point deleting additional items will result in removal of the oldest trash entries to reclaim space. Folder sizes include their descendants, and a folder tree is removed as a whole item. Automatic removal displays a desktop notification showing the number of entries permanently deleted and the space reclaimed. An incoming item larger than the limit is refused with an error before removing any existing trash entries. The original item and existing trash entries are preserved.

Deleted files retain their original names in the files subfolder. If a name is already present, Geeqie adds a numeric suffix before the file extension, for example image.2.jpg, to make it unique without preventing the file type from being recognized.

For each file, the info subfolder contains a freedesktop.org-compatible .trashinfo file recording its original path and deletion date. A folder tree has one information file for the top-level folder, preserving the names of all its contents.

When viewing the files subfolder in Geeqie, right-click a file or folder to copy or move it back to its recorded original location. Copying leaves the trash entry intact; moving removes it after a successful restore. Existing destinations are not overwritten. If the original parent no longer exists, use Restore to another folder to choose a destination.

Files created by older versions, with a six-digit prefix, remain in the Safe Delete folder and are still included when enforcing the maximum size or clearing the trash.

Use system Trash bin

Moves deleted files to the system-defined trash bin.

Use no trash at all

Selects permanent deletion as the default. The folder context menu still offers Move to Trash; that explicit action uses the last selected trash location without changing this default.

Folder

The location of the folder used by the Safe Delete feature.

Maximum size

The size limit for Geeqie trash, in MiB. The default for new configurations is 5120 MiB (5 GiB). The control accepts limits up to 102400 MiB (100 GiB). Existing saved limits are preserved. Setting this value to 0 (zero) disables the limit.

Clear button

Removes all files contained in the Safe Delete folder.

View button

Changes the Geeqie main window to display the deleted files in the Safe Delete folder.

Behavior

Check subfolders for expansion arrows

This will allow Geeqie to read sub folder content to determine if it should display expander indicators in the folder tree view.

Disable this if Geeqie wakes up auto mounted network shares, or takes too long to initially display the folder view.

In place renaming

When renaming a single file, this will allow the rename entry to appear directly over the original filename.

List directory view uses single click to enter

If selected, a single click will enter a directory, rather than the GTK+ default of a double click.

Circular selection lists

If selected, when traversing a list of selected images using Next or Previous Image, when the last or first image is encountered the focus moves to the beginning or end of the list. When deselected, focus will go no further than the start or end of the list.

Auto next folder

If selected, when the last image in the current folder is reached using Next Image, Geeqie will automatically advance to the first image in the next sibling folder. Likewise, when the first image is reached using Previous Image, Geeqie will automatically go to the last image in the previous sibling folder.

Save marks on exit

Save all marks that have been set. Note that marks that are linked to a keyword will always be saved irrespective of this setting.

Use "With Rename" as default for Copy/Move dialogs

Move the "With Rename" button to the default position.

Permit duplicates in Collections

If this option is set, an image can be inserted into a Collection any number of times.

Hide window in fullscreen

When alt-tabbing, prevent Geeqie window showing twice.

Hide OSD in fullscreen

Hide Overlay Screen Display in fullscreen mode.

Recent folder list maximum size

This is the maximum number of entries to be displayed in the recent open folder list drop-down box.

Recent collections list maximum size

The maximum number of recently opened or saved collections retained between sessions. The default is 100, and the range is 1 to 1000. Open collection combines this history with files in the default collections directory; the limit applies only to history entries. Unavailable collections remain in history and appear grayed out in the list. Existing .gqv files in this history are also updated when images are renamed or moved within Geeqie, even if the collections are saved outside the default collections directory. This setting is independent of the recent folder list and does not control Open recent, which uses GTK's shared recent-files database.

Recent folder-image list maximum size

The last image viewed in a folder is stored in a list. This value is the maximum number of entries in the list. When a folder is subsequently re-opened, focus moves to the last image viewed in that folder.

Drag'n drop icon size

This is the width and height of the icon generated from image and displayed when doing drag and drop actions. High resolution screens may require to increase this number.

Drag'n drop default action

When using drag and drop to copy or move files, the default action is to use a pop-up menu to permit you to select which action is to be taken. This option allows you to set the default action to either Copy or Move.

When using the pop-up menu, the menu will also include an option for a symbolic link and any other plugins that are defined as being a filter. If you set the default action to Copy or Move these additional options will not be available to you.

Copy path clipboard selection

This option determines which clipboard selection is used for the "Copy path" menu item. The exact method of the paste operation will depend on the operating system, but in general will be:

Primary

Paste using mouse middle-click, or shift-insert.

Clipboard

Paste using mouse right-click and select paste, or control-v.

Both

Paste using either method.

Navigation

Progressive keyboard scrolling

This will cause image panning speed to gradually accelerate when holding down the keyboard arrows.

Keyboard scrolling step multiplier:

Defines the amount to pan an image when using the keyboard arrows.

Mouse wheel scrolls image

The default is for the mouse wheel to change the image, and to scroll the image when Shift is used in combination with the wheel. Enabling this swaps the behavior so that operating the wheel will scroll the image, and holding down Shift will change the image.

Show bird's-eye view when zoomed in

When enabled, zooming or panning an image that is larger than the image pane temporarily displays an overview of the complete image. The overview indicates the visible region and can be clicked or dragged to pan the image. It hides automatically after a short period of inactivity. This option is disabled by default.

Navigation by left or middle click on image

If selected, mouse left-click will select the next image; mouse middle-click will select the previous image.

Open archive by left click on image

If selected, mouse left-click on an image belonging to the archive class will decompress the file contents and display them in a new Geeqie window.

Play video by left click on image

If selected, mouse left-click on an image belonging to the video class will start a program chosen in a box below.

Mouse button Back/Forward

Some mice have additional buttons designated Back/Forward (mouse buttons 8 and 9). You may allocate any menu item to either of these buttons.

Debugging

Debug level

Displayed when compiled with the option --enable-debug-log. This defines the verbosity of debug info sent to console and log window (0 disables the debug output).

Log Window max. lines

The maximum number of data lines to be displayed. The window will show the most recent data.
