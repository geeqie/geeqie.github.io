Color scheme

Select Follow desktop, Light, or Dark to control the interface appearance. The default follows the desktop preference. Changes take effect when you confirm the Preferences dialog; Cancel leaves the current scheme unchanged. Custom themes may not provide both light and dark variants.

The command-line option --color-scheme=system|light|dark overrides this preference for the running application session without changing the saved setting. For example, geeqie --color-scheme=dark requests a dark interface. If Geeqie is already running, the override applies to its existing windows and remains active until it exits. system follows the desktop even if the saved preference specifies Light or Dark. Changing the saved preference does not replace an active command-line override.

This setting controls the interface theme. Custom image background colors configured in Image preferences remain separate.

Thumbnails

The files pane loads visible thumbnails first, then prefetches approximately one screen of thumbnails on either side. Loading resumes as you scroll or resize the pane; it does not generate thumbnails for the entire folder. This applies to both list and icon views, including collections and expanded file groups.

Thumbnail memory (MiB) sets the memory budget for retained thumbnail pixels shared by all file panes. The default is 64 MiB. Older thumbnails are released and reloaded from the disk cache or source image when needed. Visible thumbnails and active loads are protected, so they can exceed the budget. This setting does not limit total application memory, image decoding buffers, display textures, or file-list metadata, and does not change the disk cache.

Size

Selects the size of the thumbnails displayed throughout Geeqie, dimensions are width by height in pixels.

Quality

Selects the method to use when scaling an image down for thumbnails:

Nearest

Fastest scaler, but results in poor thumbnail quality.

Tiles

Thumbnail results are very close to bilinear, with better speed.

Bilinear

High quality results, moderately fast.

Cache thumbnails and sim. files

Enable this to save thumbnails and sim. files to disk. Subsequent requests for a thumbnail will be faster, as will searches and find duplicates.

Use Geeqie thumbnail style and cache

Thumbnails are stored in a folder hierarchy that mirrors the location of the source images. Thumbnails have the same name as the original appended by the file extension .png.

The root of the hierarchy is:

$XDG_CACHE_HOME/geeqie/thumbnails/ or, if $XDG_CACHE_HOME is not defined: $HOME/.cache/geeqie/thumbnails/

Store thumbnails local to image folder (non-standard)

When enabled, Geeqie attempts to store cached thumbnails closer to the source image. This way multiple users can benefit from a single cache, thereby reducing wasted disk space.

Thumbnails have the same name as the original appended by the file extension .png.

The resulting location is the source image's folder, in a sub folder with the name .thumbnails

When the image source folder cannot be written, Geeqie falls back to saving the thumbnail in the configured Geeqie cache folder.

Use standard thumbnail style and cache, shared with other applications

This will use a thumbnail caching method that is compatible with applications that use the standard thumbnail specification. When this option is enabled thumbnails will be stored in:

$XDG_CACHE_HOME/thumbnails/ or, if $XDG_CACHE_HOME is not defined: $HOME/.cache/thumbnails/

All thumbnails are stored in the same folder, with computer-generated filenames. Refer to Thumbnails Reference for additional details.

Use Geeqie thumbnail style and custom folder

The folder field selects a parent folder. Geeqie creates a dedicated geeqie-cache subfolder for its thumbnails and .sim files, and marks it as a Geeqie cache. Existing nonempty folders without this marker are not adopted. Select Use Geeqie thumbnail style and cache to restore the default location. A dedicated folder on a larger local or network drive can reduce local disk usage. Existing cache files are not moved. Shared-style thumbnails remain in their standard location, while their .sim files use the configured Geeqie cache folder.

Use EXIF thumbnails when available

Geeqie will extract thumbnail from EXIF data if available, instead of generating one. This will speed up thumbnails generation, but the EXIF thumbnail may be not in sync with the image if it was modified by a tool which did not also update the thumbnail data.

Thumbnail color management

Where possible store thumbnails with an sRGB color profile.

Selecting this option will increase the time taken to generate thumbnails.

You probably will want to deselect the "Use EXIF thumbnails" option.

Color labels

Color labels identify images using the XMP text field Xmp.xmp.Label. Enable Show color labels to display a small indicator over icon thumbnails and beside filenames in list view. The indicator's tooltip shows the stored label text. Color labels are separate from numbered marks and star ratings.

The default mappings are Red, Yellow, Green, Blue, and Purple. Each entry specifies the text to store for that color. Change these entries to match the label names used by other applications. Matching ignores letter case; use different names for each color. An empty entry disables assignment for that color. Changing a mapping changes how existing labels are displayed, but does not rewrite their metadata.

Unknown label text is preserved and displayed with a neutral indicator. Geeqie uses Xmp.xmp.Label, not the separate Xmp.photoshop.LabelColor property. Color-label metadata support requires Exiv2.

In the files pane, right-click selected images and use Color label to assign a label or Clear color label to clear it. Writes follow the existing metadata confirmation, grouped-file, and image or XMP sidecar settings. Legacy comment files cannot store labels; choose image or XMP storage instead.

Use the Label drop-down in Show File Filter to show one color, unlabeled images, or images with other labels. All labels disables the label filter. Filtering may require reading metadata for every image in the folder. With no label filter, indicator metadata is read only for displayed rows.

Star Rating

The characters used to display the Star Rating are defined here. They are defined as a hexadecimal Unicode character. The complete list of Unicode characters can be found in many places on the Internet.

Slide show

Delay between image change
Specifies how long each image is displayed in a slide show, in seconds. The delay starts after the image has finished loading and rendering, so slow-loading images are not skipped. When a transition is enabled, the delay starts after the transition finishes.
Random
When enabled, slide show images will appear in random order.

Random images are displayed such that each image appears once per cycle of all images. When the slide show repeat option is enabled, the image order is randomized after completing each cycle.

Repeat
This will cause the slide show to loop indefinitely, it will continue with the first image after displaying the last image in the slide show list.
Transition

Choose a transition: None (the default), Cross-fade, Slide in each direction or paired directions, Over and Under in each direction, paired Over directions, and Rotate left, right, or left/right. Paired transitions alternate direction between slides. The outgoing view remains visible until the incoming image is ready. Manual navigation or stopping the slide show cancels the transition. Desktop animation settings are respected.

Transition duration (milliseconds)

Sets the transition duration, from 50 to 5000 milliseconds (default 300). Image loading and transitions extend the time between image changes. The outgoing view is retained in memory until the transition finishes.

Image loading and caching

Decoded image cache size

Limit the amount of memory available for caching images.

JPEG decode memory limit (MiB)

Sets the maximum estimated memory for decoding one JPEG image, from 1 to 65536 MiB (default 1024 MiB). Increase this limit to open very large JPEG images. Rendering, caches, other images, and decoder overhead require additional memory. The limit is also capped by the process address space.

Preload nearby images

Enabling this option preloads nearby full images while idle, following the direction in which you navigate. Images to preload selects the maximum number, from 1 to 32 (default 4). Reversing direction replaces pending work. Preloading follows the displayed order and, when navigating a selection, stays within that selection. It also works with collections. This is separate from thumbnail loading.

The decoded image cache size limits the preloaded working set, including the current image. Preloading stops when that budget is exhausted; a zero cache size disables preloading. Decoding one candidate and rendering may temporarily require additional memory. Increasing the image count does not guarantee that all candidates will fit in the cache.

Refresh on file change

Geeqie will monitor currently active images and folders for changes in their modification time, and update the display if it changes.

Disable this if the system will not go into sleep mode due to occasional disk activity from the time check, or if Geeqie updates too often for folders with continuously changing content.

Menu style

Use a ≡ "hamburger" style menu button instead of the standard menu across the top of the frame.

Geeqie must be restarted for changes to take effect.

Expand menu/toolbar

Expand the menu/toolbar to the full width of the window.

Geeqie must be restarted for changes to take effect.

Hide Selectable Bars

The menu item Hide Selectable Bars will toggle display of the bars selected here. The default keystroke for this action is control + backtick

Geeqie must be restarted for changes to take effect.

Show predefined keyword tree

Deselecting this option will hide the list of predefined keywords on the right-hand side of the keywords pane of the info sidebar.

Geeqie must be restarted for the change to take effect.

Timezone Database

The timezone database is used to correct exif time and date for UTC offset and Daylight Saving Time as described here. This option allows you to install or update the database. An Internet connection is required.

On-line help search

An internet search engine may be used to search the help files on Geeqie's website. The string used to conduct the search is defined here. In most cases it will be in one of two formats:

https://www.search-engine.com/search?q=site:geeqie.org/help

https://www.search-engine.com/?q=site:geeqie.org/help'
