Sort Manager Sidebar

The Sort Manager sidebar provides a convenient method to quickly sort many files into a set of folders or collections.

To toggle display of the Sort Manager select View ▸ Sort Manager ( Shift+S ) .

The mode of the Sort Manager is selected by the drop down list under the sidebar title. The Folder mode allows moving or copying the visible image to a folder, and the Collection mode allows adding the visible image or file selection to a collection.

  • Using a highlighted destination
  • Folder view
  • Collection view

Using a highlighted destination

Hold Ctrl and click a folder or collection to select it as the destination without processing any images. The destination remains highlighted when focus returns to the file list. Folder and collection destinations are remembered separately when switching modes and across restarts.

To process images without clicking the destination again, assign a keyboard shortcut to Sort Manager: Process images using highlighted destination in Edit ▸ Preferences ▸ Keyboard. No shortcut is assigned by default. This action is available while the Sort Manager is visible.

In Folders mode, the shortcut applies the selected Copy, Move, or Desktop action to the selected images using the highlighted folder. In Collections mode, it adds the current image or selected images to the highlighted collection, according to the selection style. Clicking a destination normally both highlights it and performs the operation.

The Help button opens this Sort Manager help page.

Folder view

The Sort Manager folder view consists of a vertical list for bookmarking folders, a section to select the operation to perform, and a set of buttons along the bottom.

Clicking or activating an item in the list will copy, move, or link the active image's file to that location. The active image will then change to the next image.

Bookmark list

This is a list of possible folders to use as a destination for the selected operation. A context menu will appear by right clicking on an item, or pressing the menu key when the item has the focus.

Folders can be added to the list by activating the Add button at the bottom of the sidebar, or dragging a folder onto the list.

By default, folder destinations are shared across source folders and Geeqie windows. Enable Use destinations for this folder to use a separate destination list for the currently displayed source folder. The list starts empty; use Add or drag destination folders onto it.

For example, configure Nature, Sports, and People as destinations while viewing Downloads, then configure Cycling, Skiing, and Swimming while viewing Sports. Geeqie switches lists when you navigate. The setting applies to that exact source folder, without inheritance by subfolders. Windows displaying the same source folder share its list.

Turning the option off restores the shared list and retains the folder's separate list for later use. Switching lists clears the highlighted destination, so select a destination before using the keyboard action to process images. Folder associations and destination lists are saved in Geeqie's configuration; no configuration files are created in image folders. Renaming or moving a source folder does not transfer its association to the new path. Collections mode is unaffected.

To edit an item select Properties from its context menu. A dialog will appear allowing the Name, Path, and Icon for the item to be changed. Select OK to close the dialog and apply the changes, or Cancel to close the dialog and discard the changes.

To change the order of the list, select Move up or Move down from the item's context menu. To move an item with the keyboard move the focus to that item, then press Shift+Up or Shift+Down to move the item.

To remove an item from the list select Remove from it's context menu.

Copy, Move, Link and Desktop actions

Clicking a folder sets and highlights the destination and processes the selected images. Hold Ctrl while clicking to set the destination only. The Sort Manager: Process images using highlighted destination action repeats the selected operation using that folder. A shortcut can be assigned in Keyboard preferences.

Plugins whose desktop files contain X-Geeqie-Filter=true also appear in the folder action list. Selecting a plugin and clicking a destination passes that folder to the plugin. See Geeqie desktop file keys for the filter key and how a plugin retrieves its destination.

Add button

Activate this button to add a folder to the bookmark list. A dialog will appear to allow selection of the folder to use for the new item.

Undo button

Activate this button to undo the last copy, move, or link operation. The undo function can only reverse the most recent operation.

Collection view

The Sort Manager collection view consists of a vertical list of collection, a section to determine the current selection, and a set of buttons along the bottom.

Clicking or activating an item in the list sets it as the destination and adds images according to the selection style below. Hold Ctrl while clicking to set the destination without adding images. The destination remains highlighted when focus returns to the files pane. The highlighted folder and collection destinations are remembered separately across restarts.

The Sort Manager: Process images using highlighted destination action adds images to the highlighted collection according to the selection style below. It works while the Sort Manager is visible. In Folders mode, it processes the selected images using the highlighted folder and the selected Copy, Move, or Desktop action. No shortcut is assigned by default; one can be assigned in Keyboard preferences.

Collection list

This is the list of collections located in the folder listed in Configuration Files , together with collections added from other folders. Activating a member of this list will result in the current image selection to be added to the collection. If the image already exists within the collection, it will not be added a second time.

An existing collection or a new empty collection can be added to the list by activating the Add button at the bottom of the sidebar.

Choosing the selection style

The images to add when activating a collection is determined by the selection style:

Add current image

The visible image is added to the collection.

Add selected images

All images selected in the file list will be added to the collection.

Add button

Activate this button to choose an existing .gqv collection or enter a new .gqv filename. Existing collections are added without changing their contents; a new filename creates an empty collection. Collections outside the default collections folder are remembered and remain available in the list. The added collection becomes the highlighted destination.

Undo button

Activate this button to undo the last add operation. The undo function can only reverse the most recent operation.
